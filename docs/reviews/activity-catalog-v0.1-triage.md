## 아르곤의 고유명사 "교정" 대조 결과

사용자가 설치한 한국어 패치 STRINGS(240개 파일, 약 7만 8천 문자열)와 대조했다.

- **아르곤의 교정이 틀린 것 10개**
  - 메리디아의 성유물 → 실제는 메리디아의 등불
  - 일리나타 → 일리날타의 심처
  - 탈스가르 → 방랑자 탈스가
  - 드라우그르 → 드로거
  - 바렌지아의 돌 → 바렌자이아의 보석
  - 암석관절염 → 관절염
  - 불의 숨결 → 화염 숨결
  - 키나레스 신전 → 키나레스의 신전
  - 노드 벌꿀주 → 노드 벌꿀술
  - 사슴 고기 스튜 → 사슴고기 스튜
- **반만 맞은 것 1개**: 촛불 → 실제는 마법의 촛불
- **맞은 것 6개**: 거울, 거침없는 힘, 브리즈홈, 잠자는 거인 여관, 페일, 방패 돌진

웹의 한국어 표기는 판본마다 다르다. 설치된 STRINGS를 먼저 조회한다는 설계(design-draft 7.6)의 근거가 하나 더 생겼다.

## 분류

### 구조를 바꾸는 지적 (활동 목록 v0.2, 설계 초안 v0.4에 반영)

| 출처 | 지적 | 분류 | 반영 |
|---|---|---|---|
| Codex | "묶음"이 개별 기록을 버리면 "모든 활동을 세세하게"라는 요구와 충돌한다 | 수용 | **보관과 전달을 나눴다.** 원시 관측은 모두 보관한다(봉인 조각은 압축). "묶음"은 AI에게 넘길 때만 적용한다. 버리는 것은 예산을 넘었을 때의 detail뿐이고, 그 사실을 기록한다. |
| Codex | 피해 훅은 세 vtable(Actor, Character, PlayerCharacter)이 필요하다 | 수용 | 설계 4.3 |
| Codex | Calamity와 공존하려면 설치 순서가 문제다 | 수용, 보완 | 툴리우스 소설가는 **늦게 설치하고, 슬롯에 들어 있던 함수를 그대로 이어 부르며, 절대 건너뛰지 않는다.** Calamity는 사용자의 모드이므로 체인 규약을 맞출 수 있다. |
| Codex | 훅 인자 damage는 "실제 깎인 체력"이 아니다 | 수용 | `reportedDamage`, 관측한 체력 전후, 검증된 감소량, 추정을 나눈다. 0단계에서 피해 적용 시점을 확인한다. |
